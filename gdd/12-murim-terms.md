# 12. 무림 테마 — 용어 정본과 작명 규칙

이 게임의 세계관은 **무림 하나**입니다. 이 문서는 **용어의 정본**이며,
다른 gdd 문서와 `web-demo/`의 모든 표시 문자열은 여기를 따릅니다.

원안과 채택 과정은 [ideanote/002](../ideanote/002-murim-theme.md),
저작권 검토는 [ideanote/007](../ideanote/007-ip-safety.md)에 있습니다.

## 12-1. 왜 테마를 바꾸는가

이유는 둘이고, 둘 다 실익입니다.

1. **세계관이 규칙을 대신 설명합니다.** "메모리 게이지가 E2로 넘어갔다"는
   규칙을 아는 사람만 읽지만, "기세가 적에게 넘어갔다"는 처음 보는 사람도
   읽습니다.
2. **디지몬 고유 명칭에서 벗어납니다.** `메모리 게이지`, `테이머`, `옵션`은
   디지몬 카드게임의 시스템·카드 종류 명칭입니다. **게임 규칙 자체는
   저작권 대상이 아니지만 이름은 아닙니다** — 메커니즘은 자유롭게 빌려
   써도 되고, 실제로 그렇게 설계했습니다. 바꿔야 하는 건 표현뿐입니다.

## 12-2. 용어 정본

| 옛 표기 | 정본 | 영문 가안 |
| --- | --- | --- |
| 메모리 게이지 | **기세(氣勢)** | Momentum |
| 턴이 넘어가는 사건 | **선(先)이 넘어간다** | the initiative passes |
| 카드 코스트 | **틈** | Opening |
| `P6 … 0 … E6` | **아6 … 0 … 적6** (我/敵) | Me / Foe |
| 턴 | **합(合)** | Exchange |
| 드로우 액션 | **숨 고르기** | Catch Breath |
| BREAK | **파훼(破解)** | Break |
| 기절 | **무너짐** | Stagger |
| 취약 | **사혈 노출** | Exposed |
| 약화 | **내상** | Wounded |
| 지속 효과 — 자기 강화 | **심법** | Inner Art |
| 지속 효과 — 장 전체 | **진법** | Formation |
| 카드 티어 | **경지** | Realm |

### 왜 "기세"인가

이 자원의 정의는 "내가 가진 양"이 아니라 **하나의 축을 둘이 나눠 갖고,
`0`을 넘으면 소유권이 상대에게 넘어가는 것**입니다. 그래서 이름은
**양방향으로 흐르는 것**이어야 합니다.

- **내공은 탈락합니다.** 내 내공이 상대에게 넘어갈 수는 없습니다.
- **선(先)**은 숫자로 쓸 수 없습니다("선 2를 내주고" ✗). 대신 뒤집히는
  사건의 이름으로만 씁니다("선이 적에게 넘어갑니다" ◎).
- **기세**는 소모·뒤집힘·반환·원리 네 자리를 모두 통과하고, 한국어 화자에게
  설명이 필요 없습니다 — "기세 싸움"이라는 말이 이미 있습니다.

검증 문장:

> 3합째 — 아5의 기세로 시작. \[매화점점\](틈 2) → \[낙매분분\](틈 2) →
> 연환 \[매화만개\](틈 3) → 기세가 **적2**로 넘어가 선이 적에게 넘어갑니다.

"게이지", "메모리", "코스트"가 한 번도 안 나오는데 무슨 일이 일어났는지
읽힙니다. 이게 테마 교체의 목적 전부입니다.

## 12-3. 바꾸지 "않는" 말

> **테마 단어는 세계관이 규칙을 대신 설명해 주는 자리에만 씁니다.**
> 카드게임의 구조 용어는 일반어로 남깁니다.

| 유지 | 이유 |
| --- | --- |
| 카드 · 손패 · 덱 · 더미 | 번역하면 뜻이 사라집니다. `손패`에 `수중(手中)`을 붙여도 영어판에서는 결국 `Hand`가 되고, 붙였던 뜻만 없어집니다 |
| 방어도 · 피해 · 회복 | 그대로 `Block` / `Damage` / `Heal`. 무협 단어로 바꿀 값어치가 없습니다 |

판단 기준은 하나입니다 — **번역해도 살아남는 단어만 무림 단어로 바꿉니다.**
`메모리 → 기세`는 통과합니다. `Memory`는 이 게임에서 아무 뜻도 없는 SF
잔재지만 `Momentum`은 규칙을 설명하니까요.

## 12-4. 초식 작명 규칙

- **기본형은 한글 4자.** 5자를 넘으면 카드 UI에서 줄바꿈이 생깁니다.
  4자로 고정하면 카드 목록이 시각적으로 정렬됩니다.
- 소재는 사자성어 + 자연물(매화·구름·파도) + 동물(용·호랑이·학).
- **경지가 오를수록 스케일을 키웁니다** — 땅 → 사람 → 하늘 → 천지.
  이름만으로 티어가 읽힙니다.
- **무공명은 직접 짓습니다.** 자료에서 본 이름은 *구조*만 참고하고,
  검색해서 특정 작품이 나오는 이름은 버립니다 (12-6).

## 12-5. 경지 — 카드 티어와 스테이지 난이도의 공통 눈금

| 경지 | 카드 티어 | 스테이지 |
| --- | --- | --- |
| 삼류 · 이류 | 티어1 | 1~3 |
| 일류 · 절정 | 티어2 | 4~7 |
| 초절정 · 화경 | 티어3 | 8~10 |
| 현경 · 생사경 | (미사용) | — |

경지 체계가 8단계라 티어 3단계보다 촘촘합니다. **현경·생사경은 일반 보상
풀에서 빼 둡니다** — 최상위 두 칸을 "존재는 아는데 아직 못 본 것"으로
남겨 두면, 나중에 해금 시스템이 들어올 때 쓸 자리가 이미 마련돼 있습니다
([ideanote/004](../ideanote/004-hidden-card-unlocks.md), 보류 중).

## 12-6. 이름에 관한 원칙 (저작권)

> 법률 자문이 아닙니다. 공개 배포 전에는 별도 확인이 필요합니다.
> 상세 근거는 [ideanote/007](../ideanote/007-ip-safety.md)에 있습니다.

**게임 규칙은 저작권 대상이 아닙니다.** 문제가 되는 건 언제나 **표현** —
이름, 문구, 아트, 세계관 설정입니다. 그래서 규칙은 자유롭게 설계하고,
이름만 관리합니다.

| | 쓴다 | 안 쓴다 |
| --- | --- | --- |
| 문파명 | 화산 · 무당 · 아미 · 청성 — 대부분 **산 이름**이라 식별력이 약합니다 | **실존 사찰·법인명**. 소림사는 이름을 관리하는 단일 주체가 있어 **금강사(金剛寺)**로 대체했습니다 |
| 설정 | 구파일방 · 오대세가 · 경지 체계 · 정사마 구도 — 장르 관용구 | 특정 작품의 인물·설정 |
| 무공명 | 직접 지은 이름 | 20세기 작품의 무공명. 출처가 불확실하면 쓰지 않습니다 |
| 문화 요소 | 오행 · 오방색 · 현무 신앙 — 전통 문화 | 실존 문파의 로고·상징물 |

판단 기준은 "실존하느냐"가 아니라 **"식별력 있는 단일 브랜드냐"**입니다.
**관리 주체가 보이면 바꿉니다.** 이름 교체 비용은 항상 분쟁 비용보다
쌉니다.
