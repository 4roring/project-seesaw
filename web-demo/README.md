# Timeline Seesaw — Web Demo

`gdd/` 폴더의 기획 문서를 기반으로 만든 빌드 도구 없는 순수 HTML/CSS/JS
프로토타입입니다. 레드 아키타입 13장 + MVP 보스 스펙만 구현되어 있습니다.

## 실행 방법

Node.js 없이도 바로 열 수 있습니다.

```bash
open index.html
```

드래그 앤 드롭(HTML5 Drag and Drop API)이 `file://`에서 정상 동작하지
않는 브라우저도 있으니, 문제가 있으면 로컬 서버로 열어주세요.

```bash
python3 -m http.server 8000
```

이후 브라우저에서 `http://localhost:8000` 접속.

## 구현 범위

**스테이지 1~10 런 전체**가 플레이 가능합니다 — 4색 덱 선택 → 전투 →
보상(새 카드 / 카드 강화) → 회복 → 다음 스테이지. 구현된 규칙은 아래
문서들을 그대로 따릅니다.

| 규칙 | 문서 |
| --- | --- |
| 게이지·턴 교대·자원 반환 | [01](../gdd/01-core-system-gauge.md) |
| BREAK(E6) 판정 | [02](../gdd/02-boss-intent-thresholds.md) |
| 보스 기술 루프 (오프너/클로저, 최소 반환 보장, 쿨다운, 인텐트 미리보기) | [08](../gdd/08-boss-skill-loop.md) |
| 지속 효과(테이머/옵션), "다음 카드 한 장" 보너스 유지 | [06](../gdd/06-persistent-effects.md) |
| 패스 메모리 리스크, 핸드 유지형 드로우, 콤보 드로우 | [07](../gdd/07-turn-economy-revision.md) |

플로팅 표시, 게이지 위로 메모리가 떨어지는 연출, BREAK 화면 연출,
카드 드래그 앤 드롭, 실시간 적 인텐트 미리보기를 포함합니다.

| 파일 | 역할 |

## 밸런스 현황 (자동 플레이 50런 기준)

| 덱 | 클리어율 | 평균 도달 스테이지 |
| --- | --- | --- |
| 블랙 | 56% | 9.8 |
| 레드 | 0% | 7.2 |
| 옐로우 | 0% | 6.5 |
| 블루 | 0% | 6.2 |

간단한 자동 AI 기준이라 실제 플레이어는 더 잘하겠지만, **컬러 간 격차가
크게 남아 있습니다.**

### 진단: 화력이 아니라 생존 문제

시뮬레이션으로 확인한 내용입니다.

- 고티어 카드 피해를 올려도(티어2 6.5 · 티어3 8.0 피해/코스트) 블랙만
  올라가고 나머지는 그대로 → 화력은 병목이 아님
- 적 피해를 15% 낮추면 블랙이 80%로 **격차가 더 벌어짐** → 전역 하향은 오답
- 원인: **블랙만 피해 경감 수단(방어도·반격)을 가짐.** 레드는 방어도 5짜리
  수비 3장, 블루는 방어 수단 없음, 옐로우는 회복 5로 페이즈당 10~15 피해를
  감당 못 함

다음 단계는 적 수치 조정이 아니라 **레드/블루/옐로우에 각 컬러다운 경감
수단을 주는 것**입니다 (예: 블루는 되감기로 턴을 벌어 피격 횟수 자체를
줄이는 방향, 옐로우는 회복량 상향).

## 기획 문서에 없어서 임의로 정한 값

gdd에 규칙으로 적힌 수치는 위 표의 문서를 보시고, 아래는 데모를 굴리려고
이 구현에서만 정한 값들입니다 — 밸런스 튜닝 시 가장 먼저 검토할 대상입니다.

| 항목 | 값 | 비고 |
| --- | --- | --- |
| 플레이어 최대 체력 | 70 | gdd 미기재 |
| 약화(Weaken) 배율 | 카드 피해 -25%, 다음 내 턴 한정 | gdd는 "약화 1턴"까지만 정의 |
| 취약(Vulnerable) 배율 | +50% (플레이어는 다음 피격 1회 소모) | gdd는 지속시간/배율 미기재 |
| 플레이어 방어도 | 매 플레이어 턴 시작 시 0으로 초기화 | 로그라이크 덱빌딩 장르 관례 |
| 보스 방어도 | 자연 감소 없음(플레이어 피해로만 소모) | gdd 미기재 |
| 보스 기술 피해량 | 일반공격 3 / 강타 6 / 광역강타 11 | 클로저 규칙 도입 후 시뮬레이션으로 재조정 (E1 평균 12.5 / E5 19.0) |
