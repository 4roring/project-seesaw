# 타임라인 시소 (Timeline Seesaw)

플레이어와 보스가 **하나의 게이지를 공유**하는 덱빌딩 로그라이크
프로토타입입니다. 게이지는 자원이면서 동시에 턴의 소유권이라, 카드를
쓸수록 주도권이 상대에게 넘어갑니다.

```text
[플레이어 구역]                 중립                 [보스 위협 구역]
 P6 ─ P5 ─ P4 ─ P3 ─ P2 ─ P1 ─ [0] ─ E1 ─ E2 ─ E3 ─ E4 ─ E5 ─ [E6: BREAK]
```

- **턴 교대:** 카드 비용만큼 게이지가 오른쪽으로 밀리고, `0`을 초과하는
  순간 내 턴이 강제 종료됩니다.
- **보스 반격:** 보스도 비용이 있는 기술을 써서 게이지가 음수가 될 때까지
  되밀어냅니다 (플레이어 턴 종료 규칙과 대칭).
- **작게 넘길수록 크게 돌아온다:** 보스 페이즈를 끝내는 마지막 기술은 항상
  "쓸 수 있는 것 중 가장 비싼 것"이라, 살짝만 넘기면 큰 기술이 마무리로
  나오면서 그만큼 깊은 버퍼가 돌아옵니다 (최소 `P3` 보장).
- **BREAK:** 게이지를 `E6`까지 밀어붙이면 보스 행동을 통째로 취소하고
  기절 + 취약을 겁니다. 덱 콤보를 쏟아부어 노릴 최종 목표입니다.

## 웹 데모 실행

Node.js 없이 바로 열립니다.

```bash
open web-demo/index.html
```

드래그 앤 드롭이 `file://`에서 동작하지 않는 브라우저라면 로컬 서버로:

```bash
python3 -m http.server 8123 --directory web-demo
```

이후 브라우저에서 `http://localhost:8123` 접속.

## 현재 구현 범위

레드 덱 13장 + 스테이지 1 보스의 **단일 전투**가 구현되어 있고,
게이지 애니메이션 / 카드 드래그 앤 드롭 / 실시간 보스 인텐트 미리보기가
동작합니다. 스테이지 1~10 런 진행, 나머지 3개 컬러, 유물 시스템은
기획만 되어 있고 미구현입니다 — [gdd/09-run-structure.md](gdd/09-run-structure.md)
참고.
