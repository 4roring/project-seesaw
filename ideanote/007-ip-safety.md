# 007. 저작권 · 상표 검토 — 무엇을 쓰고 무엇을 버리는가

## 한 줄로

무협 클리셰(장르 관용구)와 전통 문화는 마음껏 쓰고, **특정 작품·회사의
고유 창작물**은 이름 하나도 들이지 않는다.

## 왜 이게 떠올랐나

무림 테마([002](002-murim-theme.md))로 옮기면서 자료를 모으다 보니, 같은
"무협 용어"처럼 보여도 성격이 셋으로 갈렸습니다 — 누구의 것도 아닌 관용구,
전통 문화, 그리고 **특정 작가가 만든 것**. 셋을 구분하지 않으면 나중에
카드 이름을 전부 다시 지어야 합니다.

## 3등급 분류

### ✅ 안전 — 장르 관용구 · 전통 문화

| 항목 | 근거 |
| --- | --- |
| 구파일방 · 오대세가 구성 | **김용 소설에 없는 개념**입니다. 후대 무협, 특히 한국 무협에서 굳어진 관용 구성입니다 |
| 무당 · 화산 · 아미 · 청성 · 곤륜 등 문파명 | 대부분 **산 이름**에서 온 지명이라 식별력이 약합니다. 특정 작품의 창작물도 아님 |
| 개방 | 특정 실체가 없는 관용 조직 |
| 경지 체계 (삼류~생사경) | 여러 작품이 공유하는 관용 체계 |
| 내공 · 심법 · 초식 · 경공 · 점혈 · 암기 · 주화입마 | 장르 공통 어휘 |
| 정파 / 사파 / 마교 구도 | 장르 공통 구도 |
| 오행 · 오방색 · 오간색 ([006](006-color-factions.md)) | 전통 색채·사상 체계. 저작권 대상이 아님 |
| 현무 · 진무대제 · 무당산 신앙 | 전통 신앙 |

**게임 규칙 자체는 저작권 대상이 아닙니다.** 기세 교환, 파훼, 콤보 드로우
같은 메커니즘은 자유롭게 설계할 수 있습니다. 문제가 되는 건 언제나
**표현** — 이름, 문구, 아트, 세계관 설정입니다.

### ⚠️ 주의 — 확인이 필요한 것

| 항목 | 사유 |
| --- | --- |
| 실존 사찰·종교법인의 명칭 일반 | 산 이름과 달리 **단일 주체가 이름을 관리**할 수 있습니다. 아래 소림 항목이 그 사례입니다 |
| 실존 문파의 로고 · 상징물 | 명칭과 달리 시각 요소는 별도 권리가 있을 수 있습니다. 아트는 직접 디자인합니다 |
| 오래된 소설의 무공명 | 저작권 보호기간이 지난 작품(예: 청대 협의소설)은 안전하지만, 20세기 작품은 아닙니다. **출처가 불확실한 무공명은 쓰지 않습니다** |

## 지금 코드에 실제로 남아 있는 것

`web-demo/data.js`에서 확인된 항목입니다. 노트가 아니라 **출시물에 들어가는
문자열**이라 우선순위가 높습니다.

| 카드 | 위치 |
| --- | --- |
| `테이머: 폭주 코어` | 레드 |
| `옵션: 예열 가속` · `옵션: 균열탄` | 레드 |
| `옵션: 캐시 증폭` | 블루 |
| `옵션: 방벽 전개` | 블랙 |
| `옵션: 부패 확산` | 옐로우 |
| `메모리 되감기` · `메모리 방출` · `메모리 폭군`(적 이름) | 여러 색 |
| 상수 `MIN_MEMORY_RETURN`, 주석의 "메모리" | 전역 |

**`테이머`와 `옵션`은 접두어일 뿐이라 교체 비용이 거의 없습니다.**
[002](002-murim-theme.md)가 이미 대응물을 정해 뒀습니다 — 자기 강화는
**심법**, 장 전체에 거는 것은 **진법**. `테이머: 폭주 코어` → `심법: ~`,
`옵션: 균열탄` → `진법: ~` 형태입니다.

> **부수 효과:** 무림 테마 전환의 명분이 하나 늘었습니다. 지금까지는
> "테마가 규칙을 대신 설명한다"가 유일한 이유였는데
> ([002](002-murim-theme.md)), **디지몬 고유 명칭에서 벗어나는 것** 자체가
> 실익입니다. 메커니즘은 자유롭게 빌려 써도 되지만 이름은 아닙니다.

## 앞으로 지킬 원칙

1. **무공·초식 이름은 직접 짓습니다.** 사자성어와 자연물·동물 소재를 조합해
   만들고([002](002-murim-theme.md) 자료 6), 자료에서 본 이름은 *구조*만
   참고합니다. 검색해서 특정 작품이 나오는 이름은 버립니다.
2. **자료 노트와 게임 텍스트를 분리합니다.** `ideanote/`에 출처를 밝혀
   인용하는 것과, 그 단어를 카드에 넣는 것은 다릅니다. 인용은 남기고
   차용은 하지 않습니다.
3. **참고 작품은 메커니즘만 봅니다.** 『멸망 이후의 세계』에서 가져온 것은
   "기본기를 반복해 최상위 초식에 도달한다"는 **구조**이지 인물도 기술명도
   아닙니다.
4. **아트는 직접 만들거나 라이선스를 확인합니다.** 문파 상징, 카드 일러스트,
   폰트 모두 해당합니다. 특히 **한자 폰트의 상용 라이선스**는 놓치기 쉽습니다.
5. **실존 명칭은 "식별력"으로 판단합니다.** 실존한다는 사실 자체가 문제가
   아닙니다. 화산 · 무당산 · 아미산은 지명이라 누구의 것도 아니지만,
   소림사는 이름을 관리하는 주체가 있는 단일 브랜드입니다. **관리 주체가
   보이면 바꿉니다.**
6. **의심스러우면 이름을 바꿉니다.** 이름 교체 비용은 항상 분쟁 비용보다
   쌉니다.

## 검증하려면

1. **출시 전 전수 검사** — `data.js`의 모든 `name` 필드를 검색해서, 특정
   작품이 1페이지에 나오는 이름을 걸러냅니다.
2. **폰트·에셋 라이선스 목록** — 사용한 모든 외부 리소스의 라이선스를 한
   파일에 모읍니다. 지금은 순수 HTML/CSS/JS라 외부 의존이 없으니, 늘어나기
   전에 시작하는 게 쌉니다.
3. **상표 확인은 상용화 시점에** — 무료 프로토타입 단계에서는 과한 작업
   입니다. 다만 게임 제목과 문파명은 그 시점에 반드시 확인합니다.
