# 002. 무림 테마 전환 + 무협 자료 모음

> 상태: 🌱 씨앗 (용어표만 확정) | 적은 날: 2026-09-04

## 한 줄로

디지몬 TCG 문법에서 빌려온 현재의 무국적 SF 톤(메모리/브레이크/테이머/
옵션)을 **무림 단일 세계관**으로 갈아끼운다.

## 왜 이게 떠올랐나

현재 게임의 뼈대는 이미 무협 그 자체입니다 — 두 고수가 **한 합씩 주고받고**,
많이 움직일수록 상대에게 **틈**을 내주고, 상대가 큰 기술로 마무리하면
그만큼 내 차례가 길어집니다. 그런데 껍데기의 용어(메모리 게이지, 브레이크,
테이머, 옵션)는 이 감각과 아무 관계가 없습니다. 테마를 바꾸면 규칙을
설명할 필요 자체가 줄어듭니다 — "게이지를 0 초과로 넘기면 턴이 끝난다"보다
"크게 움직이면 상대에게 선(先)을 내준다"가 짧습니다.

## 무림 하나로 한정할 것인가 (사무라이/닌자 혼합)

**무림 단일을 권합니다.** 이유:

1. **카드 이름 규칙이 하나여야 합니다.** 무협 초식명은 사자성어 4자가
   기본 문법입니다(아래 자료 6). 여기에 "이가류 발도술"이나 "카게분신"이
   섞이면 카드를 훑을 때 리듬이 깨집니다.
2. **다양성이 부족해서 섞는 게 아닙니다.** 구파일방 + 오대세가 + 사파 +
   마교만으로 아키타입 4개는커녕 20개도 나옵니다.
3. **혼합 세계관은 "왜 여기 있나"를 설명해야 합니다.** 설명해야 하는
   설정은 카드 텍스트 공간을 먹습니다.

다만 **이국적인 맛은 무협 클리셰 안에 이미 있습니다.** "새외(塞外)" —
중원 밖 세력들(북해빙궁, 남만, 서장 밀교 등)이 그 자리입니다. 후반
스테이지의 이질적인 적은 여기서 뽑으면 세계관을 깨지 않고 낯설게 만들 수
있습니다. 왜구/동영(東瀛) 검객 계열이 무협에서 얼마나 흔한 클리셰인지는
확인이 더 필요합니다 — 흔하다면 사무라이 맛도 무림 안에서 소화됩니다.

### 왜 "기세"인가

이 자원의 정의는 "내가 가진 양"이 아니라 **하나의 축을 둘이 나눠 갖고,
`0`을 넘으면 소유권이 상대에게 넘어가는 것**입니다. 그래서 이름은
**양방향으로 흐르는 것**이어야 합니다.

- **내공은 탈락합니다.** 가장 먼저 떠오르는 후보지만, 내 내공이 상대에게
  넘어갈 수는 없습니다. 위의 핵심 성질을 만족하지 못합니다.
- **선(先)**은 숫자로 쓸 수 없습니다 ("선 2를 내주고" ✗). 대신 뒤집히는
  사건의 이름으로 남깁니다 ("선이 적에게 넘어갑니다" ◎).
- **호흡**이 유일한 경쟁자였습니다. "한 호흡에 다섯 초식"이 한 합에 여러
  장을 잇는 감각을 그대로 담습니다. 다만 게이지 이름은 뒤집힘 쪽 문장에
  더 자주 등장하고, 거기서는 "기세가 넘어갔다"가 더 자연스럽습니다.
- **기세**는 네 자리(소모 · 뒤집힘 · 반환 · 원리)를 모두 통과하고, 한국어
  화자에게 설명이 필요 없습니다 — "기세 싸움"이라는 말이 이미 있습니다.

검증 문장:

> 3합째 — 아5의 기세로 시작. \[매화점점\](틈 2) → \[낙매분분\](틈 2) →
> 연환 발동 \[매화만개\](틈 3) → 기세가 **적2**로 넘어가 선이 적에게
> 넘어갑니다.

"게이지", "메모리", "코스트"가 한 번도 안 나오는데 무슨 일이 일어났는지
읽힙니다. 이게 테마 교체의 유일한 목적입니다.

### 번역 기준 — 어떤 말을 바꾸지 "않을" 것인가

손패는 **기수식**(起手式, 투로의 첫 자세) 같은 후보를 검토했지만 바꾸지
않기로 했습니다. 기준은 이렇습니다.

> **테마 단어는 세계관이 규칙을 대신 설명해 주는 자리에만 쓴다.**
> 카드게임의 구조 용어(손패 · 더미 · 덱)는 일반어로 남긴다.

이유는 **번역**입니다. `손패`는 영어로 `Hand`면 끝이지만, `수중(手中)`
같은 말을 붙이면 영어판에서 결국 `Hand`가 되면서 붙였던 뜻이 사라집니다.
번역해도 살아남는 단어만 무림 단어로 바꿀 값어치가 있습니다.

거꾸로 `메모리 → 기세`는 이 기준을 통과합니다. `Memory`는 이 게임에서
아무 뜻도 없는 SF 잔재지만 `Momentum`은 규칙을 설명하니까요.

| 무림 | 영문 가안 | 통과 여부 |
| --- | --- | --- |
| 기세 | Momentum | ◎ 양방향으로 흐르는 것 |
| 선이 넘어간다 | the initiative passes | ◎ 한국어의 기세/선 분리가 영어에도 그대로 |
| 틈 | Opening | ◎ |
| 아 / 적 | Me / Foe | ◎ 짧은 라벨 유지 |
| 파훼 | Break | ◎ 원래 이름으로 회귀 |
| 초식 / 무공 | Form / Art | ◎ |
| 경지 | Realm | ◎ 무협 영번역의 관용 표기 |
| 숨 고르기 | Catch Breath | ◎ |
| 합 | Exchange | ◎ |
| ~~수중~~ | Hand | ✗ 번역하면 사라짐 → **손패 유지** |

> **적용 범위:** 노트 본문은 "턴"을 그대로 씁니다. `합`은 UI 문구를 실제로
> 쓸 때 적용할 표기이고, 지금 노트에서까지 바꾸면 `gdd/`의 "플레이어 턴 /
> 보스 페이즈"와 대조하기 어려워집니다. 자원 이름(기세 · 틈 · 아/적 · 파훼)만
> 노트 전체에 적용했습니다.

## 컬러 4색 → 문파 매핑 (초안)

[03-color-archetypes.md](../gdd/03-color-archetypes.md)의 기존 정체성을
**바꾸지 않고** 이름만 갈아끼우는 것이 조건입니다. 이미 4색은 시뮬레이션으로
밸런싱이 끝나 있으니, 테마가 밸런스를 건드리면 안 됩니다.

| 현재 | 문파 후보 | 근거 |
| --- | --- | --- |
| 레드 (연계 · 과부하) | **화산파** | 매화검법 계열의 연환 초식 = 이어 쓸수록 커지는 chain |
| 블루 (드로우 · 되감기) | **무당파** | 태극/사량발천근의 "되돌린다"가 기세 되감기와 정확히 겹침 |
| 블랙 (아머 · 앵커) | **소림사** | 금강불괴 = 방어도, 나한진 = 룰을 굳히는 진법 |
| 옐로우 (HP 자원화 · 흡혈 · 디버프) | **사천당가 + 마공** | 독/암기 = 확정 디버프, 흡성대법 = 흡혈. 자기 피를 쓰는 컨셉은 사파 쪽이 자연스러움 |

대안: 블루를 제갈세가(기관·진법 = 패 서치)로, 레드를 남궁세가(제왕검형 =
패도적 한 방)로 두는 조합도 성립합니다. 다만 레드는 [03](../gdd/03-color-archetypes.md)에서
"고코스트 피니셔를 접은" 아키타입이라 패도 이미지와는 어긋납니다.

## 초식 작명 규칙

- 기본형: **사자성어 4자**. 동물(용/호랑이/사자/학)과 자연물(매화/구름/
  파도)이 흔한 소재입니다.
- 실제 예: 철우경지(鐵牛耕地, 소가 밭을 간다), 사자후(獅子吼),
  매록헌화(梅鹿獻花)
- 게임용 제약: 한글 4자를 넘으면 카드 UI에서 줄바꿈이 생깁니다. 4자 고정을
  규칙으로 삼으면 카드 목록이 시각적으로 정렬됩니다.
- 티어가 오를수록 스케일이 커지는 작명(땅 → 사람 → 하늘 → 천지)으로 경지
  차이를 이름만으로 전달할 수 있습니다.

## 기존 시스템과 충돌하는 곳

거의 없습니다 — 이 노트는 **규칙을 하나도 바꾸지 않는** 것이 전제입니다.
바뀌는 것은 문자열과 아트 방향뿐입니다. 다만:

- `web-demo/data.js`의 카드 `key`는 영문 유지, `name`만 교체해야 코드
  변경이 없습니다.
- [06-persistent-effects.md](../gdd/06-persistent-effects.md)의 "테이머/
  옵션"은 디지몬 TCG의 카드 *종류* 개념이라, 무림에는 대응물이 없습니다.
  심법(자기 강화)과 진법(장 전체 효과)으로 쪼개는 게 자연스럽습니다.

## 검증하려면

테마 교체는 시뮬레이션으로 검증할 수 없습니다. 대신:

1. 레드 덱 13장의 이름만 화산 매화검법 계열로 바꿔 웹 데모에 넣어 봅니다.
2. 카드 텍스트에서 "게이지", "메모리" 같은 단어를 빼고 "기세", "틈"으로
   바꿨을 때 **규칙 설명 없이 이해되는지**만 봅니다.
3. 이해된다면 테마가 규칙을 대신 설명하고 있다는 뜻이고, 그게 이 교체의
   유일한 목적입니다.

## 자료 모음

아래는 웹에서 모은 무협 클리셰 정리입니다. 세부는 작품마다 다르고
나무위키/블로그 기반이라 **정본이 아니라 관용구 모음**으로 취급합니다.

### 자료 1. 세력 구조

- **구파일방(九派一幇):** 정파 중 명망 높은 9개 문파 + 1개 방(개방).
  소림 · 무당 · 화산 · 아미 · 곤륜 · 종남 · 점창 · 해남 · 공동(또는 청성)
  + 개방. 마지막 한 자리는 출처마다 다릅니다.
- **오대세가(五大世家):** 혈연으로 이어지는 가문. 남궁세가 · 제갈세가 ·
  사천당가 · 하북팽가 · 황보세가(또는 모용세가).
- **정파 / 사파 / 마교의 관계** — 게임적으로 가장 쓸모 있는 부분:
  - 사파는 정파의 **교정 대상**. 즉 상하 관계이며 같은 판 위에 있음.
  - 마교는 정파의 **제거 대상**. 하위 개념이 아니라 대등한 반대편.
  - → 스테이지 1~10 구성에 그대로 씁니다: 초반은 사파 군소문파(같은 판
    위의 하수), 후반은 마교(다른 규칙을 쓰는 존재). "적의 격"이 아니라
    "적과의 관계"가 바뀌는 구조라 [009-run-structure](../gdd/09-run-structure.md)의
    난이도 곡선에 서사를 붙일 수 있습니다.
- **관무불가침:** 황실과 무림은 서로 간섭하지 않는다는 원칙.

### 자료 2. 경지(境地) — 8단계

`삼류 → 이류 → 일류 → 절정 → 초절정 → 화경 → 현경 → 생사경`

| 경지 | 통상적 묘사 |
| --- | --- |
| 삼류~일류 | 훈련된 일반 무사 ~ 쓸 만한 실력자 |
| 절정 | 문파의 실무 전력 |
| 초절정 | 주변이 체급 차이를 실감하는 단계 |
| 화경 | 무공이 몸에 녹아들어 의식 없이 발현. 무공과 자신이 하나 |
| 현경 | 무공의 본질을 꿰뚫고 자연의 이치와 합일. 천하제일인급 |
| 생사경 | 생사의 경계를 초월. 존재 자체가 무공 |

→ [003](003-hap-exchange-memory.md)의 "역량에 따른 가변 기세 폭"에 그대로
쓸 수 있는 눈금입니다.

### 자료 3. 무공의 내부 구조

기본 구조: **심법으로 내공을 쌓음 → 운기법으로 내공을 소모 → 초식으로
상대의 방어를 무너뜨림 → 절초로 마무리**.

| 용어 | 뜻 |
| --- | --- |
| 내공(內功) | 체내에 기운을 축적·순환·변성·방출하는 기술 체계 |
| 심법(心法) | 무공에 적합한 심상을 만드는 정신 수련 |
| 운기법 | 쌓은 내공을 실제로 소모·운용하는 법 |
| 초식(招式) | 검이나 주먹을 휘두르는 연속 동작 단위 |
| 구결(口訣) | 초식의 이론적 설명 |
| 절초(絕招) | 치명적인 마무리 초식 |
| 구명절초 | 목숨을 구하는 비장의 한 수 |

**"심법 → 초식 → 절초"가 이 게임의 턴 구조와 1:1로 맞습니다** —
지속효과 깔기 → 저코스트 연계 → 피니셔. 카드 종류 구분에 그대로 씁니다.

### 자료 4. 무공 분류

| 분류 | 뜻 |
| --- | --- |
| 내공 / 외공 | 체내의 기 vs 신체 외부 움직임 |
| 권법 · 장법 · 지법 | 주먹 / 손바닥 / 손가락 |
| 검법 · 도법 | 검(양날) / 도(외날) |
| 신법 · 경공(輕功) | 이동·회피. 높이 뛰고 물 위를 걸음 |
| 암기(暗器) | 표창 · 비도 · 독침 · 만천화우 |
| 점혈(點穴) | 혈도(기가 흐르는 길, 365개)를 짚어 무력화 |

기타: **검기**(검에서 뿜는 원거리 기운) < **검강**(물질 파괴),
**어검술**(검이 홀로 움직임), **전음입밀**(특정인에게만 소리 전달),
**주화입마**(잘못된 수련으로 내공이 역류).

→ 분류 자체가 카드 태그 체계가 됩니다. "경공 태그 카드를 3장 쓰면" 같은
시너지 조건이 세계관과 따로 놀지 않습니다.

### 자료 5. 합(合) · 허초 · 파훼 — 이 게임의 핵심 어휘

- **합(合):** 힘을 집중시키는 타이밍의 묘리. 무협에서 "십여 합을 겨루다"
  = 주고받은 공방의 횟수 단위.
- **허초(虛招):** 페이크. 실제 타격이 아닌 유인 동작.
- **파훼(破解):** 상대의 초식을 깨뜨리는 초식.

**이 세 단어가 [003](003-hap-exchange-memory.md)의 근거입니다.** 특히
허초 — "피해는 없지만 틈을 적게 주는 초식"이라는 카드 유형이 세계관에서
바로 나옵니다. 현재 게임에 없는 카드 축입니다.

### 자료 6. 초식 작명

- 대부분 **사자성어**. 옥녀심경, 천산육양장 같은 3~5자 무공명 + 4자 초식명.
- 동물(사자·소·용·학)과 자연물이 흔한 소재.
- 예: 철우경지(鐵牛耕地), 사자후(獅子吼), 사자귀림(獅子歸林),
  사출동혈(獅出洞穴), 매록헌화(梅鹿獻花), 양춘백설, 양관삼첩.
