# 아이디어 노트 (Idea Notes)

떠오른 아이디어를 **다듬기 전에** 그대로 던져 두는 곳입니다.
[`gdd/`](../gdd/)가 "확정된 설계"라면, 여기는 "아직 확정되지 않은 것"입니다.

## gdd/ 와의 경계

| | `gdd/` | `ideanote/` |
| --- | --- | --- |
| 성격 | 확정 설계. 구현의 근거 | 미확정 발상. 검증 대기 |
| 문체 | 단정형 ("~한다") | 가정형 ("~하면 어떨까") |
| 수정 | 설계 변경 시에만 | 언제든 자유롭게 |
| 졸업 | — | 채택되면 `gdd/` 문서로 옮기고 여기엔 링크만 남김 |

## 노트 → 파일럿 → 졸업 — 누가 어디를 고치나

아이디어와 구현은 **다른 세션**에서 진행합니다. 둘 다 `main`에 바로 올리므로,
**같은 파일을 동시에 고치지 않는 것**이 이 절의 목적입니다.

| 단계 | 누가 | 고치는 곳 | 끝나는 조건 |
| --- | --- | --- | --- |
| **1. 노트** | 아이디어 세션 | `ideanote/` | 노트에 **순서 · 합격 기준 · 안 하기로 한 것**이 있다 |
| **2. 파일럿** | 데모 세션 | `web-demo/` — **지금 데모를 깨지 않게 나란히** 추가 | 노트의 합격 기준을 재서, 노트 끝 **"검증 결과"** 절에 적었다 |
| **3. 졸업** | 데모 세션 | `gdd/` + 노트 머리 · 상태(✅) | 규칙 본문과 실측이 gdd에 있고, 노트에는 링크만 남았다 |

**gdd는 파일럿이 합격한 뒤에만 고칩니다.** 이 프로젝트의 gdd에는 실측이
함께 들어가고([gdd/14-4](../gdd/14-weapons.md)처럼), 검증 전에 고치면 정본이
틀린 채로 남습니다.

### 결정은 어디서 하나

| 데모 세션이 정한다 | 아이디어 세션으로 가져온다 |
| --- | --- |
| 노트가 **수치나 (미정)** 으로 남긴 것 — 조건 N, 가중 배율, 카드 수치 · 이름 | **합격 기준을 못 넘었다** |
| 노트의 구조 안에서 끝나는 튜닝 | **구조를 바꿔야 한다** — 자원 · 동사 · 풀 구성 · 순서 |
| | 노트의 **"안 하기로 한 것"** 을 건드려야 한다 |

가져올 때는 노트의 "검증 결과"에 **무엇을 쟀고 무엇이 막혔는지**를 적고,
상태를 🔍로 둡니다. 아이디어 세션이 그걸 읽고 노트를 고칩니다.

### 예외 — 데모 세션이 노트를 고쳐도 되는 곳

- 노트 끝의 **"검증 결과"** 절
- 졸업할 때 노트 **머리의 상태 표기와 졸업 안내**

## 쓰는 법

1. [`_template.md`](_template.md)를 복사해 `NNN-짧은-제목.md`로 만듭니다
   (번호는 그냥 순번 — 우선순위가 아닙니다).
2. 다 쓰지 않아도 됩니다. 제목 한 줄 + 아이디어 한 문단이면 충분합니다.
3. 아래 색인에 한 줄 추가합니다.

## 용어

**무림 용어의 정본은 [gdd/12-murim-terms.md](../gdd/12-murim-terms.md)로
졸업했습니다.** 노트를 쓸 때는 그 문서를 따릅니다 — **기세**(게이지),
**틈**(코스트), **아/적**, **합**(턴), **파훼**(BREAK), **숨 고르기**
(드로우 액션).

## 상태 표기

| 상태 | 뜻 |
| --- | --- |
| 🌱 씨앗 | 방금 적음. 아직 아무것도 검증 안 됨 |
| 🔍 검토중 | 시뮬레이션/데모로 확인해 보는 중 |
| ✅ 채택 | `gdd/`로 졸업. **규칙 본문은 gdd에만 둡니다** |
| 🔶 부분 채택 | 일부만 졸업. 무엇이 남았는지 노트 머리에 적습니다 |
| ⏸ 보류 | 지금은 안 함. **지우지 말고** 이유를 남길 것 |
| ↪ 대체 | 다른 노트가 자리를 가져감. **지우지 말고** 어디로 갔는지와 남길 원칙을 머리에 적을 것 |

보류된 아이디어를 지우지 않는 이유: 같은 발상이 몇 달 뒤에 또 떠오르는데,
그때 "왜 접었는지"가 남아 있으면 같은 검증을 두 번 하지 않아도 됩니다.

**채택된 노트의 규칙 본문은 gdd로 옮기고 노트에는 남기지 않습니다.** 정본이
둘이면 반드시 어긋나고, 그때 어느 쪽이 맞는지 아무도 모르게 됩니다.
