# 타임라인 시소 (Timeline Seesaw)

플레이어와 상대가 **하나의 기세(氣勢)를 나눠 갖는** 무림 덱빌딩
로그라이크 프로토타입입니다. 기세는 자원이면서 동시에 선(先)의
소유권이라, 초식을 쓸수록 주도권이 상대에게 넘어갑니다.

```text
[아(我) 구역]                          중립                [적(敵) 구역]
 아6 ─ 아5 ─ 아4 ─ 아3 ─ 아2 ─ 아1 ─ [0] ─ 적1 ─ 적2 ─ 적3 ─ 적4 ─ 적5 ─ 적6
```

- **선(先)의 교대:** 초식의 **틈**만큼 기세가 오른쪽으로 밀리고, `0`을
  초과하는 순간 내 합이 강제로 끝납니다.
- **적의 반격:** 적도 틈이 있는 초식을 써서 기세가 음수가 될 때까지
  되밀어냅니다 (플레이어 쪽 규칙과 완전히 대칭).
- **작게 넘길수록 크게 돌아온다:** 페이즈를 끝내는 마지막 초식이 무엇이냐가
  돌아오는 기세를 정합니다. 최소 `아3`은 보장됩니다.
- **파훼(破解):** **한 합에 지불한 틈의 합계**가 그 적의 **빈틈**을 넘으면
  적의 행동을 통째로 취소하고 무너짐 + 사혈 노출을 겁니다. 깊은 버퍼를
  받을수록 많이 몰아칠 수 있으므로, **버퍼를 쌓는 것이 곧 파훼에 가까워지는
  것**입니다.

### 적 10종은 두 축으로 서로 다른 싸움이 됩니다

| 축 | 뜻 | 플레이어에게 묻는 것 |
| --- | --- | --- |
| **빈틈** (6~13) | 파훼에 필요한 한 합의 총 틈 | 몰아쳐서 파훼를 노릴 것인가 |
| **클로저 성격** | 패도(가장 비싼 초식으로 마무리) / 노회(가장 싼 것) | 버퍼를 쌓는 플레이가 통하는가 |

노회형은 얕게 넘겨도 최소 보장만 돌려주므로 **버퍼 축적 자체를 막습니다** —
난이도가 아니라 전술을 바꾸는 스탯입니다.

## 네 문파

| 자(紫) | 마교 | `lifesteal` — 입힌 피해를 체력으로 | 흡혈 |

## 웹 데모 실행

Node.js 없이 바로 열립니다.

```bash
open web-demo/index.html
```

드래그 앤 드롭이 `file://`에서 동작하지 않는 브라우저라면 로컬 서버로:

```bash
python3 -m http.server 8123 --directory web-demo
```

## 현재 구현 범위

**스테이지 1~10 런 전체**가 플레이 가능합니다 — 4문파 중 선택 → 전투 →
보상(새 초식 / 강화) → 회복 → 다음 스테이지. 1:1 가로 대전 구도, 공격·피격
모션, 기세가 떨어지는 연출, 파훼 연출, 실시간 인텐트 미리보기가 동작합니다.

자동 플레이 200런 기준 클리어율은 자 79% · 흑 65% · 백 62% · 적 49%이며,
격차와 그 원인 분석은 [web-demo/README.md](web-demo/README.md)에 있습니다.

유물, 분기형 맵, 런 간 해금은 아직 미구현입니다 —
[gdd/09 9-6](gdd/09-run-structure.md)과 [`ideanote/`](ideanote/)의 보류
항목을 참고하세요.
