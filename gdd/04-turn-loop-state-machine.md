# 4. 턴 루프 및 상태 머신 (State Machine)

```text
[전투 시작] (플레이어 P3 세팅)
      │
      ▼
┌─ [플레이어 턴] ────────────────────────────────────────┐
│ 0. 지속 효과 처리: 턴 시작 트리거형 효과 발동 → 잔여 턴 감소 →  │
│    만료된 효과 제거 (6장 참고)                             │
│ 1. 핸드 보충: 손은 유지, 직전 턴에 사용한 카드 수만큼만 드로우   │
│    (전투 시작 턴만 예외적으로 5장 전체 드로우 — 7장 참고)    │
│ 2. 콤보 카운터 초기화 (0)                                     │
│ 3. 카드 사용: 비용만큼 게이지가 오른쪽(+)으로 전진               │
│    (즉시 적용형 지속 효과가 있으면 피해/취약 계산에 반영)         │
│    → 콤보 카운터 +1, 3에 도달 시 카드 1장 추가 드로우 후 리셋    │
│ 4. 실시간 UI: 게이지 위치에 따른 보스 반응 인텐트 표시          │
│ 5. 분기점 체크: 게이지가 0을 초과했는가?                         │
│    ├─ NO : 카드 계속 사용 가능 (또는 "패스"로 자진 종료 가능 —   │
│    │        패스 시 게이지 +3 메모리 리스크, 7장 참고)        │
│    └─ YES: 플레이어 턴 즉시 강제 종료                          │
└─────┬─────────────────────────────────────────────────┘
      │
      ▼
┌─ [보스 판정 페이즈] ────────────────────────────────────┐
│ 게이지 도달 위치 확인:                                        │
│  ├─ 보스 기절 상태: 이번 페이즈는 아무 기술도 못 씀             │
│  │   └─ 게이지를 P(n)으로 이동, 기절 해제                      │
│  ├─ E6 도달: [BREAK] 발동!                                   │
│  │   └─ 보스 행동 취소, 기절 부여, 게이지 P3 복귀              │
│  └─ E(n), n=1~5 도달: 보스 기술 루프 시작 (8장 참고)         │
│      └─ 쿨다운 감소 → 사용 가능한 기술 중 최우선순위 선택       │
│         → 비용만큼 게이지를 왼쪽(-)으로 이동 → 효과 적용        │
│         → 게이지가 아직 0 이상이면 반복                        │
│         → 게이지가 음수가 되는 순간 페이즈 종료 (자원 반환)     │
└─────┬─────────────────────────────────────────────────┘
      │
      ▼
┌─ [승리/패배 체크] ─────────────────────────────────────┐
│  ├─ bossHp ≤ 0 : 플레이어 승리 (전투 종료)                    │
│  ├─ playerHp ≤ 0 : 플레이어 패배 (전투 종료)                  │
│  └─ 둘 다 아님 : 계속 진행                                     │
└─────┬─────────────────────────────────────────────────┘
      │
      ▼
[턴 카운트 증가 & 플레이어 턴으로 루프]
```

보스 페이즈의 종료 조건("게이지가 음수가 되는 순간")은 플레이어 턴의
종료 조건("게이지가 0을 초과하는 순간")과 완전히 대칭입니다 — 자세한
내용은 [08-boss-skill-loop.md](08-boss-skill-loop.md) 참고.
