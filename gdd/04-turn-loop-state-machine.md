# 4. 합의 루프 및 상태 머신 (State Machine)

> 용어는 [12-murim-terms.md](12-murim-terms.md)를 따릅니다 — 기세 · 틈 ·
> 아/적 · 합 · 파훼 · 무너짐 · 숨 고르기.

한 **합(合)**이 어떤 순서로 흐르는지, 어디서 선(先)이 넘어가는지를
한 장에 모읍니다. 각 단계의 *이유*는 다른 장에 있고, 여기는 **순서**가
정본입니다.

## 4-1. 한 합의 흐름

```text
[비무 시작] — 기세 아3에서, 카드 5장을 쥐고 시작
      │
      ▼
┌─ [내 합] ───────────────────────────────────────────────┐
│ 0. 합 시작 정리                                              │
│    · 방어도 0으로, 반탄 소멸 (둘 다 적 페이즈 하나만 버틴다)   │
│    · 이번 합의 몰아치기 · 연환 카운터 0으로                   │
│ 1. 심법 · 진법 처리: 합 시작 효과 발동 → 남은 합 감소 →        │
│    만료된 것 제거 (6장)                                      │
│ 2. 손패 보충: 손은 유지하고, 직전 합에 손에서 빠져나간 수만큼만 │
│    뽑는다 (사용 + 파기 − 미리 당겨 쓴 수 — 7-2)              │
│ 3. 초식 사용: 틈만큼 기세가 적 쪽(+)으로 밀린다                │
│    · 이번 합의 **몰아치기**에 그 틈을 더한다 (파훼의 재료)      │
│    · 되감기가 있으면 그만큼 되민다 (틈 − 되감기 ≥ 1 — 11-5)   │
│    · 연환 카운터 +1, 3에 닿을 때마다 카드 1장 추가            │
│ 4. 화면: 지금 넘기면 적이 무엇을 할지 미리 보여 준다 (2장·8장)  │
│ 5. 분기: 기세가 0을 **초과**했는가?                           │
│    ├─ 아니오: 계속 낸다. 또는 **숨 고르기** —                 │
│    │          기세 2를 내주고 카드 1장 (7-1).                │
│    │          숨 고르기의 기세는 몰아치기에 **넣지 않는다**    │
│    │          (2-1). 0을 넘지 않으면 합은 이어진다.           │
│    └─ 예:    선(先)이 적에게 넘어간다 — 내 합 즉시 종료        │
└─────┬───────────────────────────────────────────────────┘
      │  넘긴 위치 = 적n (n = 1~6). 이 n이 적의 이번 페이즈 예산이다
      ▼
┌─ [적 페이즈] ───────────────────────────────────────────┐
│ 먼저 두 가지를 차례로 본다.                                   │
│                                                            │
│ ① 적이 무너져 있는가?                                       │
│    └─ 그렇다 → 이번 페이즈는 초식을 하나도 못 쓴다.           │
│                무너짐을 풀고 기세만 되돌린다.                 │
│ ② 파훼인가? — **이번 합의 몰아치기 ≥ 그 적의 빈틈** (2-1)     │
│    └─ 그렇다 → 적 페이즈를 통째로 취소.                      │
│                다음 합까지 **무너짐**, 다음 합에 **사혈 노출**  │
│                (받는 피해 +50%), 기세는 **아3**으로 복귀.      │
│                ※ 빈틈은 적마다 다르다(5~9). 기세 축의 칸이     │
│                   아니라 "한 합에 몰아쳐야 하는 총 틈"이다.    │
│                                                            │
│ 둘 다 아니면 적 초식 루프 (8장)                                │
│    └─ 쿨다운 감소 → 쓸 수 있는 초식 중 우선순위 최고를 고름     │
│       → 틈만큼 기세를 내 쪽(−)으로 되민다 → 효과 적용          │
│       → 기세가 아직 0 이상이면 반복                           │
│       → 음수가 되는 순간 페이즈 종료                          │
│    · 페이즈를 끝내는 **마지막 초식**이 돌아오는 기세를 정한다.  │
│      패도형은 가장 비싼 것, 노회형은 가장 싼 것 (8-4-1)        │
│    · 돌아오는 기세는 **최소 아3 보장**, 하한 아6 (8-4-4)       │
└─────┬───────────────────────────────────────────────────┘
      │
      ▼
┌─ [승패 판정] ───────────────────────────────────────────┐
│  ├─ 적 체력 ≤ 0 : 승리 (비무 종료)                           │
│  ├─ 내 체력 ≤ 0 : 패배 (비무 종료)                           │
│  └─ 둘 다 아님 : 계속                                        │
└─────┬───────────────────────────────────────────────────┘
      │
      ▼
[합 수 +1 → 다시 내 합으로]
```

## 4-2. 두 종료 조건은 대칭이다

| | 끝나는 조건 | 어디까지 미는가 |
| --- | --- | --- |
| 내 합 | 기세가 `0`을 **초과**하는 순간 | 적1 ~ 적6 |
| 적 페이즈 | 기세가 **음수**가 되는 순간 | 아1 ~ 아6 (최소 아3 보장) |

`0`에 **정확히** 멈춘 합은 끝나지 않습니다. 중립이므로 계속 낼 수
있습니다 — [01-core-system-gauge.md](01-core-system-gauge.md) 1-1.

이 대칭이 "작게 넘길수록 크게 돌아온다"를 만듭니다. 살짝만 넘기면 적의
큰 초식이 예산 안에 안 들어가 마무리로 밀려 나오고, 그만큼 기세가 깊게
돌아옵니다 ([08-boss-skill-loop.md](08-boss-skill-loop.md) 8-4).

## 4-3. 파훼는 "착지 위치"가 아니라 "몰아치기"다

**합이 끝나는 순간 한 번만** 판정합니다. 재료는 그 합에 **초식으로** 낸
틈의 합계이고, 숨 고르기는 들어가지 않습니다.

- 몰아치기가 합 도중에 빈틈을 넘어도 합은 멈추지 않습니다. 마지막
  일격이 상대를 무너뜨리는 그림입니다.
- 되감기로 번 틈은 몰아치기에 **남습니다** — 합을 늘리는 것이 곧
  파훼에 가까워지는 길입니다.
- 무너짐 판정이 파훼 판정보다 **먼저**입니다. 이미 무너진 적에게는
  파훼가 따로 발동하지 않습니다.

경계값·근거·폐기된 옛 규칙("기세 착지 위치가 `적max` 이상이면 파훼",
실측 파훼율 0~1%로 사장)은 [02-boss-intent-thresholds.md](02-boss-intent-thresholds.md)
2-1에 있습니다.
